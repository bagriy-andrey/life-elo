# Roadmap

Двигаемся сверху вниз. Каждая задача перед реализацией превращается в план `docs/plans/NN-slug.md`
(роль planner), затем `/build-plan`. Отметка `[x]` — когда план выполнен и проверен.

## 0. Алгоритм
- [ ] **Рейтинг v1** — зоны, лимиты, серии, Elo. План готов: `docs/plans/01-scoring-ruleset-v1.md`.

## 1. Начать пользоваться
- [ ] **Деплой на Vercel + установка на iPhone** — автодеплой из GitHub, инструкция «На экран Домой».
      Собрано (README, `docs/setup/backend.md`), ожидает ручной проверки: деплой и iPhone (пользователь).
- [ ] **Бэкап: экспорт / импорт JSON** — защита истории до появления синхронизации.
- [ ] **Облако привычек при создании + свои** (п. 6, 8) — каталог из §4 контекста, выбор тапом, своя привычка.
- [ ] **Заметки** (п. 1, без ИИ) — заметка к привычке за день и к дню целиком в утреннем отчёте.

## 2. Навигация и экраны
- [ ] **Нижний бар, 5 вкладок** (п. 11) — Сегодня · Статистика · Привычки · Награды · Кабинет.
      «Сегодня» включает утренний отчёт.
- [ ] **Экран привычки** (п. 10) — серия, история зон, заметки, мини-календарь.

## 3. Статистика
- [ ] **Календарь-хитмап как в Strava** (п. 3, 9) — один компонент: общий и для отдельной привычки.
- [ ] **График рейтинга по дням** (п. 4) — линия Elo, тап по точке → разбор дня.
- [ ] **Статистика неделя / месяц / год** (п. 2).

## 4. Мотивация
- [ ] **Звания за рейтинг** (п. 13) — обсудить пороги и названия (нижние — нейтральные, без стыда).
- [ ] **Монеты и подарки** (п. 5) — обсудить экономику: начисление монет, цены, разблокировка за серии.

## 5. Кабинет
- [ ] **Профиль и настройки** (п. 12) — имя, возраст, фото, тема (системная / светлая / тёмная).
- [ ] **Языки: русский, украинский, английский** — i18n всего интерфейса.
- [ ] **Аккаунты и синхронизация** — вход по имейлу, данные в облаке (бэкенд, например Supabase).
      Собрано (план 04), ожидает ручной проверки по чек-листу в `docs/setup/backend.md` §8.
      Меняет правило «No backend» в `AGENTS.md` — обновить при планировании.
